Voxel Verse (prototype)

Quickstart

- Requirements: Node 18+ (Node 22 tested)
- Install: npm install
- Dev server: npm run dev
- Build: npm run build
- Preview build: npm run preview

Controls

- Click canvas to lock pointer
- WASD to move, mouse to look

What’s included

- Three.js renderer and basic directional/ambient lighting
- Simple chunked voxel terrain built from noise
- Pointer-lock FPS camera with ground-following raycast

Notes

- This is a vertical slice prototype, not an optimized or content-complete game. Performance and features can be expanded with greedy meshing, texture atlases, instancing, streaming chunks, physics, and networking.
